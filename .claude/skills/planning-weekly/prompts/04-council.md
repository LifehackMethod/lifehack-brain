# Phase 4 — The Council  ·  HUD `[4/6] THE COUNCIL`

**Paint the HUD on entry:** `bash "$ROOT/system/tools/skill_hud.sh" set '🧭 Cal · Weekly   [4/6] THE COUNCIL · pressure-testing · next → Action'`

**Desired outcome:** the ranked plan from Phase 3 is deliberately biased (we seeded it with the monthly plan on
purpose). Before it gets written, six fresh-context sub-agents each take a different angle and return **tensions
and alternatives — never a replacement plan**. the person reviews and decides: fold in / loop back to Phase 3 / hold.
The Council never re-ranks. He keeps the pen.

**Rolling scratchpad view first:** show Phase 3's additions (ranked Win(s) · 2×2 triage · calendar plan-of-intent).

**Built ON the `advisory-council` skill** (blind diverge → argue → converge, human-chaired). ★ Build note: the
"argue/converge" step can manufacture false consensus — **preserve each member's independent dissent** through it.

## Run
1. Dispatch the six members (`council/*.md`) as fresh-context **OPUS** sub-agents (Phase 4 IS the `advisory-council` engine — the sole named opus exception per global CLAUDE.md Subagent Model Selection, 2026-07-20; their reasoning quality IS the deliverable), blind to each other and to the session's reasoning. Each gets a **thorough brief** — the full plan, explicitly framed as *"our best current thinking, not prescriptive — challenge it"* (that framing IS the de-bias; "red team" is banned — the label makes members perform adversarialism instead of thinking). Mode is **hybrid**: April re-derives blind; the others critique under a neutral charge.
2. Each returns findings: a scannable **one-line headline + full reasoning/evidence underneath** (never headline-only — the work isn't lost).
3. Cluster + dedupe to the handful of tensions that genuinely matter. Present them **numbered**, each with your **best-guess disposition** (fold in / loop back to Phase 3 / hold), so he triages fast and drills into any.
4. He decides per item. On a loop-back, Phase 3 re-runs ONLY the flagged items. Sweep dispositions to the pad.

## The six members (full angles in `council/`)
April (10th Man — a *different, simpler* conclusion) · Time Supply (hard math: free hrs vs task-hrs → surplus/
deficit) · Blind Spot Detector (the 11 priority-selection biases, one per turn only when warranted) · Touchdown
Dance (celebrate real wins; flag over-scheduling after a big result) · Long-Lens/Ponzi (is this week robbing Peter
to pay Paul?) · The Builder (leverage against recurring pain — automation, or an untapped feature in software he
already pays for). All **opus** (the advisory-council engine's designed opus exception; Fable unavailable in CLI). Count = independence, not headcount. *(Cost note: 6 opus advisors/run is heavier than the rule's "small roster 2–4"; justified by the weekly cadence + quality-is-the-deliverable — the person can down-scope to sonnet if cost bites.)*

## do NOT
- do NOT let any member return a replacement plan or re-pick the Win — tensions/alternatives ONLY.
- do NOT use adversarial/"red-team" framing — neutral charges; give them the plan as "a draft to challenge."
- do NOT auto-fold — every disposition is the person's call; you propose, he decides.
- do NOT collapse dissent to premature agreement in the converge step.

## Output contract
Scratchpad = the plan, pressure-tested — surfaced tensions + the person's dispositions folded. `✅ phase 4 complete`.
