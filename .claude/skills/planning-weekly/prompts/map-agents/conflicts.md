# Map-agent — Angle 1: CONFLICTS

**Your one angle:** tensions and conflicts in the existing data. Overlapping commitments, things that can't both be
true, contradictions between what the person said he'd do and what's actually on the calendar, promises colliding with
capacity. (Formerly "clear the surfaces.")

Read the week's window for THESE only. Surface each conflict as a headline + the two things in tension + a pointer.
Rank biggest-friction first. Pre-draft the questions that would resolve each (with your best guess).

Return in the shared Map format (`_map-format.md`). Do NOT resolve the conflicts, rank-to-drop, or conclude —
surface and point-to; the session and the person resolve them later.
