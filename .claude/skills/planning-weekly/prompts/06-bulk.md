# Phase 6 · Step 3 — Bulk the Similar  ·  HUD `[6/6] TRIAGE · Bulk`

**Paint the HUD on entry:** `bash "$ROOT/system/tools/skill_hud.sh" set '🧭 Cal · Weekly   [6/6] TRIAGE · Bulk · next → individually-handle'`

**Objective:** clear same-fate items in ONE counted gesture. Present them as **block lines** — "24 × archive
(done-by-event) — one line, expand to inspect" — so the attention surface stays scannable. **Cap ~10 expanded
attention rows at a time**; more contested than that → split it. Each block/row carries its id/permalink. One
approval gesture per block ("all / all except #N / per-row").

Dead pile (from Step 2) + any other obvious same-fate clusters (registry noise, done-by-event) flow through here.
**Archiving is destructive → it only fires on the person's explicit approval of the block.**

## do NOT
- do NOT put a human/tender thread, an in-name draft, or anything with a live ask into a bulk block — pull it out for individually-handle.
- do NOT execute a block before the person approves it; read a sample back to verify after.
- do NOT exceed ~10 expanded rows — collapse the ✓-obvious into counted blocks.

## Output contract
Approved blocks executed (via the safe stack) + verified + swept to the scratchpad; counts tallied. `✅ bulk cleared`.
