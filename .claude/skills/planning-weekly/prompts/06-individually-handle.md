**Paint the HUD on entry:** `bash "$ROOT/system/tools/skill_hud.sh" set '🧭 Cal · Weekly   [6/6] TRIAGE · Individual · next → park/wrap'`

**Objective:** the threads that can't be bulked — real human relationships, negotiations, tender situations — get
individual attention, one row each with full context (pull the real body via the store / a sub-agent; never off a
title). Main-inbox-only scope; rely on the inbox's own filtering for newsletters/promos.

**The email-as-task-vector row rules (borrowed from an outside framework, task-app-neutral):**
- **Human-written email → archive ONLY alongside a reply draft OR an explicit "no-reply-because X."** Never archived silently alone.
- **Self-sent email → convert to a Google Task if it carries an ask; archive if superseded; never reply.**
- **In-name content (a draft) → shown as FULL TEXT, its own row, never in a bulk block.** Draft-only, never sent.
- **Tender thread → surfaced individually, never ghostwritten, never bulked.** When in doubt, tender.
- A destructive move on an ambiguous referent ("archive that guy's email") → name + confirm the target first.

Present each as a numbered row + Cal's best-guess disposition (draft / task / no-reply-because / keep); the person
confirms or overrides by number. Drafts flush individually only after their text was approved.

## do NOT
- do NOT send any email (draft-only); do NOT archive a human email without a paired draft or stated no-reply.
- do NOT ghostwrite or bulk a tender thread; do NOT act on an ambiguous referent before naming it.
- do NOT reply to a self-sent email — convert-or-archive only.

## Output contract
Each thread → a drafted reply, a stated no-reply, a task, or a kept state; all confirmed + swept to the scratchpad.
