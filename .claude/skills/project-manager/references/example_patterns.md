# Example Patterns

These are examples of possible project doc structures. They are not templates. Choose or invent the structure that fits the work.

## Troubleshooting / diagnosis

Possible sections:
- Current state
- System architecture
- Symptoms and data
- Settings/configuration
- Active test
- Test ledger
- Hypothesis map
- Theory action plans
- Expert questions
- Open uncertainties
- Latest update

Use when:
- user is debugging a system
- tests and observations accumulate
- facts and hypotheses can easily blur

## Book / essay / intellectual project

Possible sections:
- Current thesis
- Audience and promise
- Voice and style rules
- Argument map
- Chapter/section structure
- Source and example bank
- Decisions made
- Open tensions
- Drafting plan
- Deprecated framings

Use when:
- the work is conceptual or creative
- structure and thesis evolve
- future AI needs to preserve voice and argument continuity

## Business strategy / product development

Possible sections:
- Desired outcome
- Current offer/product
- Target customer
- Market/customer insight
- Positioning hypotheses
- Experiments run
- Evidence gathered
- Strategic decisions
- Constraints
- Next bets
- Risks

Use when:
- the work involves market learning, offers, operations, positioning, or product decisions

## Creative worldbuilding / fiction

Possible sections:
- Core premise
- World rules
- Character truths
- Timeline
- Plot threads
- Tone and style
- Continuity constraints
- Open mysteries
- Deprecated ideas
- Next scenes/artifacts

Use when:
- consistency matters across a large creative system

## Personal operating system / coaching

Possible sections:
- Desired outcome
- Current reality
- Constraints
- Current practices
- Experiments
- Lessons learned
- Patterns observed
- Decisions
- Next iteration
- Watchouts

Use when:
- the user is iterating on behavior, routines, relationships, productivity, or personal change

## Research exploration

Possible sections:
- Research question
- Current answer
- Sources reviewed
- Evidence map
- Competing interpretations
- Open questions
- Confidence levels
- Next research targets
- Draft conclusions

Use when:
- the work involves gathering evidence and refining understanding
