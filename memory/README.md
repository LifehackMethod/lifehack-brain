# This folder is a leftover. Your writing is NOT here.

**Everything you write lives in your AI Brain** — a separate folder in your cloud
drive, named by the one-line `.brain-root` file at the top of the Harness.
`INSTALL.md` is the authority on where it is and how the two got connected.

This directory is left over from an earlier layout. Until 2026-08-12 your writing
did live here. It does not any more, and nothing reads this folder.

**If you have put anything in here, move it into your AI Brain** — otherwise no
command will ever find it. Nothing is lost either way: git ignores this folder, so
an update cannot touch what you wrote in it.

You do not need to create anything by hand. Run `/ingest` and it builds the shape
inside your AI Brain as it goes: a folder per subject, and inside each one a place
for the things that stay true and a place for the things that happened on a date.
