# SEMANTIC fixture — the class ONLY the judge can catch

⚠ **THIS FILE CONTAINS NO HUNTED STRING.** Not a name, not an address, not a path, not a
key — in any encoding, casing, or obfuscation. Run it through `push_gate.py` and it passes
clean, correctly, because there is nothing literal in it to find.

**And anyone who has met the person it describes could name them in about four seconds.**

That is the entire argument for the judgment pass, made concrete rather than asserted. The
mechanical half is exhaustive about what it enumerates; this is the half it structurally
cannot reach. If a future session is tempted to treat the literal gate as sufficient, run
this file through it first.

The person here is invented, like everyone else in these fixtures. What is not invented is
the SHAPE: every sentence below is a detail that no rule can enumerate and that a reader
can assemble into an identity anyway.

## Getting started

This system was built by someone who does three jobs that have nothing to do with each
other — restores historic barns for a living, keeps a small pottery studio on the side, and
does their own books every spring. Three corners of one life, each with its own routine,
and none of them a software job.

They built it because things kept going missing between sessions: a decision made in March
that nobody could find again in June.

Their younger sibling, a commercial airline pilot, settled the distribution question on a
recorded call: ship it as a public repository rather than a zip file, because a zip copies
a folder structure and does not enforce it — and with a non-technical audience that
difference is the whole ballgame.

The teaching is the business. The software is free.
