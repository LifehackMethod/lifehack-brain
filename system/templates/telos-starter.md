# TELOS

> **What this is.** One page saying what you are optimizing for this year. It loads into your sessions
> and orients them, so it is worth being honest in rather than impressive in. Nobody else reads it.
>
> **How to use this starter:** copy it to `<notes>/state/telos.md` and replace every prompt below with
> your own words. Delete the prompts as you go — a leftover prompt is how you can tell a section was
> never actually answered. The `/telos` skill will walk you through it if you would rather be asked.
>
> ⛔ **Do not fill this in with tactics.** Every line should name a STATE you want to be in, not a
> method for getting there. "Run three times a week" is a method. "Be someone whose body is not the
> limiting factor" is a state. The test: if it names a tool, an app, or a routine, it is the wrong
> altitude — write down what that thing is FOR instead.
